## 通过

- `npm run typecheck`、`npm run format:check`、`npm run build:app`。
- `npm test`：34 个文件，370 项测试全部通过。最后调整歌单匹配索引与翻译进程生命周期后，重新通过类型、格式及 `tests/unit/online.test.ts` 的 14 项专项测试。

- AM 专项覆盖：资料库 ID 与目录 ID 区分、无目录 ID 的上传曲目、公开网页令牌解析、账号验证前不保存、取消后不保存、分页链接限定、完整分页/不完整快照拒绝、目录关系展开失败回退、账号切换、官方播放链接、受保护下载拒绝、专用会话退出清理、登录窗口隔离与导航限制。
- 更新后的 `tests/online-desktop.cjs` 全流程通过并查看截图：AM 在同一平台/账号/歌单入口，账号确认、远端歌曲和官方播放链接正常，AM 不会加入文件下载队列。账号/API 为模拟服务。
